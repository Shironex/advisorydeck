# Security policy

## Reporting a vulnerability

Report vulnerabilities in this project's code, workflows or published feed privately through GitHub: **Security > Report a vulnerability** on this repository. Please do not open a public issue.

Examples: a way to make the notifier image post content it should not, a flaw in how the feed or its manifest could be tampered with, a leaked secret, or a workflow that runs untrusted code with write access.

You can expect an acknowledgement within a week. This is a one-person project, so fixes take as long as they take; you will be told what is happening.

## Not a vulnerability

- A wrong or outdated curated note: use the [wrong note report](../../issues/new?template=wrong-note.yml).
- A missing or late advisory for a product: open an issue.
- A vulnerability in a product the catalog lists (PostgreSQL, Traefik, ...): report it to that vendor.

## Supported versions

Nothing is released yet. Once the image ships, only the latest release gets fixes.
